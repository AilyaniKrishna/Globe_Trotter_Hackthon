# GlobeTrotter frontend prototype

Open `index.html` in a modern browser to use the responsive, dependency-free prototype.

Implemented screens: Login / signup (1-2), Home (3), Create Trip (4), My Trips (5), Itinerary Builder (6), Profile (7), Discover / City and activity search (8), Itinerary with budget (9), Community (10), Calendar (11), and Admin dashboard (12).

Interactions included: login/signup toggle, prototype sign-in routing, sidebar navigation, new-trip routing, profile-save feedback, discover search and filter selection, calendar event rendering, and links between related screens.
